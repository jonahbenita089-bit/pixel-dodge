# BB Racing

A lightweight browser racing game inspired by classic arcade road-racing gameplay.

## Play locally

Open `index.html` in a browser.

## Controls

- A / D or Left / Right arrows to steer
- Start button to begin or restart the race

## Files

- `index.html` – page layout
- `style.css` – styling and HUD
- `game.js` – game logic and rendering

## Goal

Stay alive, dodge incoming traffic, and rack up the highest score possible.
